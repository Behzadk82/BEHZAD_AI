# BEHZAD AI نسخه 0.4

## قابلیت‌های این نسخه
- ذخیره دائمی پیام‌های کاربر و پاسخ‌های سرور در SQLite
- بارگذاری تاریخچه پس از بستن و بازکردن صفحه
- ذخیره یادداشت پروژه در تنظیمات
- تهیه نسخه پشتیبان دستی از پایگاه داده
- ایجاد نسخه پشتیبان هنگام راه‌اندازی سرور (در صورت وجود پایگاه داده)
- بازیابی نسخه پشتیبان با تأیید کاربر
- سازگار با اجرای محلی Termux و میزبانی‌هایی که متغیر PORT ارائه می‌کنند

## اجرا در Termux
از پوشه پروژه:
```bash
python main.py
```
سپس:
`http://127.0.0.1:8000`

## اطلاعات ذخیره‌شده
پایگاه داده در `data/behzad_ai.sqlite3` ساخته می‌شود.
نسخه‌های پشتیبان در `data/backups/` قرار می‌گیرند.
این پوشه‌ها را حذف نکنید؛ برای انتقال پروژه، کل پوشه `data` را نیز نگه دارید.

## API
- `GET /api/health`
- `GET /api/history`
- `POST /api/chat`
- `GET /api/settings`
- `POST /api/settings`
- `GET /api/backups`
- `POST /api/backup`
- `POST /api/restore`

## نکته مهم
پاسخ گفت‌وگو در این نسخه همچنان آزمایشی است و به مدل زنده ChatGPT متصل نیست.
ذخیره‌سازی روی همان سروری انجام می‌شود که برنامه روی آن اجرا شده است. اگر سرویس میزبانی فایل‌سیستم موقت داشته باشد، باید فضای ذخیره‌سازی پایدار یا پایگاه داده مدیریت‌شده تنظیم شود.
این نسخه هنوز احراز هویت و کنترل دسترسی برای پنل پشتیبان‌گیری ندارد؛ آن را بدون محافظت روی اینترنت عمومی منتشر نکنید.
